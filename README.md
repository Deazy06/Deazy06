## Projects

### 🚇 SL Departures on ESP32

An ESP32-based Stockholm public transport departure board.

The project uses an **ESP32 Dev Module** with an **SSD1306 128×64 I2C OLED** to display upcoming SL Metro departures.

Features include:

* Fetches SL departure information automatically
* Configurable station name and SL site ID
* Web-based configuration interface
* Settings persist across reboots using flash storage
* LittleFS station database
* Automatic refresh every 15 seconds
* Displays upcoming Metro departures
* Serial diagnostics and countdown
* Separate ESP32 test environment without the OLED

The project is built with **PlatformIO** and communicates with the ESP32 over Wi-Fi.
